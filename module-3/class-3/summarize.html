Git Basic Commands

  1. git init:কোনো নতুন লোকাল প্রজেক্টে গিট ব্যবহার শুরু করার জন্য এটিই প্রথম কমান্ড।
  2. git add . :প্রজেক্টের ফোল্ডারে থাকা সবগুলো পরিবর্তনকে (নতুন ফাইল, পরিবর্তিত ফাইল বা ডিলেট করা ফাইল) commit করার জন্য Staging Area-তে ফাইল যুক্ত করবে।
  3. git commit -m "message or description":এই কমান্ডটি আপনার প্রজেক্টের বর্তমান অবস্থার একটি স্ন্যাপশট বা ভার্সন তৈরি করে লোকাল রিপোজিটরিতে জমা রাখে।
